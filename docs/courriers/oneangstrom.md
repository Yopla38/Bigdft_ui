**Objet : Programme partenaire, intégration de BigDFT comme service de calcul**

Bonjour,

Nous développons une plateforme web de simulation à l'échelle atomique construite autour de BigDFT, le code de DFT en ondelettes. Elle permet de construire un calcul en 3D, de le lancer sur des ressources louées et d'en exploiter les résultats, avec l'aide optionnelle d'un agent.

Votre programme partenaire nous intéresse comme canal complémentaire : une extension SAMSON qui appellerait notre service de calcul, sur le modèle de ce que vous proposez pour GROMACS dans le cloud. Avant d'aller plus loin, nous aimerions comprendre quelques points :

1. Le montant de la commission sur les ventes, et s'il diffère entre abonnements et facturation à l'usage.
2. Pour un service cloud facturé à l'usage : la facturation passe-t-elle obligatoirement par SAMSON Connect, ou un utilisateur peut-il relier son compte SAMSON à un compte existant chez nous ?
3. Le SDK : langages pris en charge pour une extension qui dialogue avec une API web, et accès au modèle de données pour les cellules périodiques et les données volumiques (densités, orbitales).
4. Existe-t-il, ou prévoyez-vous, un composant web de SAMSON (visualiseur embarquable, version navigateur) ?
5. Les conditions pour un usage académique, et la possibilité d'une période d'évaluation du SDK.

Nous pouvons vous montrer une maquette de l'atelier si cela vous est utile.
