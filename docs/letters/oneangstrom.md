**Subject: Partner program, integrating BigDFT as a computing service**

Hello,

We are developing a web platform for atomic-scale simulation built around BigDFT, the wavelet-based DFT code. It lets users assemble a calculation in 3D, run it on rented resources and work with the results, with optional help from an agent.

Your partner program interests us as a complementary channel: a SAMSON extension calling our computing service, along the lines of what you offer for GROMACS in the cloud. Before going further we would like to understand a few points:

1. The percentage taken on sales, and whether it differs between subscriptions and usage-based billing.
2. For a usage-billed cloud service: must billing go through SAMSON Connect, or can a user link their SAMSON account to an existing account with us?
3. The SDK: which languages are supported for an extension talking to a web API, and how the data model handles periodic cells and volumetric data (densities, orbitals).
4. Whether a web component of SAMSON exists or is planned (an embeddable viewer, a browser version).
5. The terms for academic use, and whether the SDK can be evaluated for a trial period.

We can show you a mock-up of the workshop if that helps.
